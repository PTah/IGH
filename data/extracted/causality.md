# Граф взаимосвязей (причинность)

Помимо географического пути строится **граф событий**: узлы = события (и иногда персонажи/ресурсы), рёбра = «повлияло на».

Если событие в книге **изменило** дальнейший маршрут, состав группы, сроки, транспорт или исход — оно выделяется и связывается с последствиями.

## Уровни влияния (`impact`)

| impact | Когда | Как на карте / в схеме |
|--------|--------|-------------------------|
| `critical` | Без этого весь дальнейший сюжет/путь другой | Крупная иконка + обязательное ребро к следствиям |
| `major` | Смена маршрута, потеря спутника, смена транспорта, долгая задержка | Выделенная иконка + ребро |
| `minor` | Локальный эффект (осторожнее ехали, запас топлива…) | Обычная иконка, ребро опционально |
| `flavor` | Атмосфера, без каузального хвоста | Только на линии времени, без рёбер |

`importance` (key/major/normal) — **эмоциональный/сюжетный вес** для читателя карты.  
`impact` — **сила влияния на дальнейшие события**. Могут не совпадать (трогательная сцена без смены маршрута = key + flavor).

## Типы рёбер (`link.kind`)

| kind | Пример |
|------|--------|
| `causes` | поломка → вынужденный объезд |
| `delays` | ранение → потеря дней |
| `reroutes` | блокпост / шторм → другой путь |
| `enables` | находка топлива → смогли плыть дальше |
| `prevents` | чутьё Тигра → избежали засады |
| `joins` | взяли спутника → дальше едут вместе |
| `loses` | гибель спутника → смена планов/одиночество |
| `changes_transport` | машина убита → другой транспорт |
| `weather` | шторм → снос с курса / укрытие |
| `leads_to` | мягкая связь «после этого стало возможным» |

## Модель JSON

```json
{
  "nodes": [
    {
      "id": "e-find-tiger",
      "kind": "event",
      "type": "meet_key",
      "impact": "critical",
      "importance": "key",
      "title": "Находка Тигра",
      "place_id": "p-…",
      "chapter_id": "book02-ch000",
      "pov": "protagonist"
    }
  ],
  "edges": [
    {
      "id": "l-tiger-joins",
      "from": "e-find-tiger",
      "to": "leg-…",
      "kind": "joins",
      "summary": "Тигр становится постоянным спутником; чутьё влияет на разведку и засады"
    }
  ]
}
```

Событие может ссылаться на **несколько** исходящих рёбер (одно ранение → задержка + смена тактики + medical stop).

## Примеры (шаблоны под вычитку)

| Триггер | Типичные `kind` | Что писать в `summary` ребра |
|---------|-----------------|------------------------------|
| Поломка / авария машины | `changes_transport`, `reroutes`, `delays` | куда поехали иначе / на чём |
| Ранение | `delays`, `leads_to` (медпункт) | сколько времени / смена роли |
| Шторм / непогода | `weather`, `reroutes`, `delays` | снос курса, укрытие, отложенный выход |
| Встреча спутника (Сэм, Дрика, Тигр) | `joins`, `enables` | кто дальше в группе |
| Гибель / расставание | `loses`, `reroutes` | как изменился план |
| Находка ресурса / базы | `enables` | что стало возможным |
