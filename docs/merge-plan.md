# Слияние cruz-ya-edu-domoy × I.Go.To.Home

Источник сравнения (только чтение): локальный клон первичного пробного проекта **I.Go.To.Home**  
(путь задаётся env `IGTH_ROOT` или аргументом скрипта).  
Целевой проект для улучшений: **этот** репозиторий (IGH).  
В I.Go.To.Home (ниже иногда «IGTH») ничего не писать.

```text
set IGTH_ROOT=path\to\I.Go.To.Home
python scripts/compare_igth.py
```

## Краткий вердикт

| | **cruz (мы)** | **I.Go.To.Home** |
|--|---------------|------------------|
| Суть | Вычитанный сюжетный слой + сильная карта | Полный скелет по всем главам + даты + gazeteer |
| Книга 3 curated | Да (86 глав / 38 событий) | Нет отдельного `book03_curated` |
| Точность спутников | Высокая (Сэм=Джастисбёрг, Тигр=Викенбург) | В `key_events` есть ошибки (Сэм/Тигр «в Юме») |
| Карта UX | Таймлайн, OSRM/дороги, море («Мариетта»), спутники, причинность в карточке | Книги цветом, pivots, список остановок, denser chapter points |
| Календарь | «День N» ≈ глава | Реальные даты из заголовков (21 марта…20 июля) |

**База нового «лучшего»:** наш curated + наша карта.  
**Забрать из IGTH:** даты/время из `route.json`, gazeteer (имена+coords), denser chapter spine, идеи graph/pivots, Mapbox coords где точнее, не их ошибочные key_events про Сэма/Тигра.

## Что сильнее у нас (оставить / развивать)

1. Ручные `sought` / `outcome` / человеческие summary.
2. Раздельные хабы Юма/Уэлтон/Фортуна… + маршрут по дорогам (OSRM).
3. Морские коридоры (Атлантика, «Мариетта» вокруг Дании).
4. UI: таймлайн, фильтр спутников, причинность «из‑за этого / следствие».
5. Верная арка спутников и Кронштадт как стык POV.

## Что сильнее у IGTH (импортировать к нам)

1. **`route.json`** — 164 главы с `date` / `time` / `location` / `seq` → заменить или дополнить «День N» календарём книги.
2. **`gazetteer.json`** — больше топонимов и `real`‑имён; сверить с `coords_seed.json`, добавить недостающие точки.
3. **`events.json`** — chapter-level summary + `pivots` + `density` как вторичный слой («все главы»), не вместо curated.
4. **`graph.json`** — сверить рёбра с нашими `edges`; добавить недостающие (ураган→Скайлэйн→Уичита уже есть у обеих сторон по-разному).
5. **`coords_mapbox.json` / geocode_report** — точечно поправить координаты.
6. **Карта IGTH:** цвет книги на обводке, список остановок героя, слой «ключевые ★» — перенести UX-идеи, не копировать баги данных.
7. **`text/`** у них — полный текст по главам; у нас `data/raw/` — при необходимости выровнять покрытие.

## Предлагаемая архитектура «одного лучшего»

```
data/
  extracted/          # истина сюжета (curated book01–03) — как сейчас
  spine/              # NEW: импорт из IGTH
    chapters.json     # 164 × date,time,location,seq,pov  ← route.json
    gazetteer.json    # сжатый/сверенный gazeteer
  map/                # UI на базе нашего app.js
```

Сборка `build_map_data.py`:

1. Curated events → карточки (как сейчас).
2. Spine chapters → опциональный слой «все главы» + **календарная** шкала на таймлайне.
3. Edges = union(наши edges, graph.json) с дедупом и каноническими `kind`.
4. Coords = coords_seed ⊕ gazetteer ⊕ mapbox (приоритет: ручной seed > mapbox > nominatim).
